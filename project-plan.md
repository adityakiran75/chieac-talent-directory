# ChiEAC Talent Directory
## Project Plan


## Project Overview

The ChiEAC Talent Directory is a public website designed to showcase professional profiles of ChiEAC members. The directory will provide a centralized location where recruiters, employers, partner organizations, and community members can discover member skills, education, projects, and professional interests.


## Business Problem

ChiEAC members have professional information distributed across resumes, LinkedIn profiles, emails, and other documents. Without a centralized directory, it is difficult for organizations and recruiters to identify qualified candidates.


## Project Goal

Create a simple, searchable website where visitors can:

- Browse member profiles
- Search members by keyword
- Filter profiles by skill or interest
- View education, projects, certifications, and professional links


## Target Users

### Recruiters and Employers

Users who want to discover qualified ChiEAC talent.

### ChiEAC Members

Professionals who want to showcase their skills and experience.

### ChiEAC Administrators

Staff who manage profile information.


## Technology Stack

The project will use:

- HTML5
- CSS3
- JavaScript
- JSON data
- GitHub
- GitHub Pages


## Core Features

The minimum viable product will include:

- Home page
- Talent directory page
- Search functionality
- Basic filtering
- Individual profile views
- Member submission form
- Responsive design
- Public deployment


## Project Timeline

### Week 1
Planning, design, project setup, and sample data preparation.

### Week 2
Build profile cards, search, and filtering.

### Week 3
Create detailed profiles, improve user experience, and test responsiveness.

### Week 4
Testing, deployment, documentation, and presentation preparation.


## Project Success Criteria

The project will be successful when:

- The website is publicly available.
- Visitors can search and filter profiles.
- Member information is organized and easy to update.
- The website works on desktop and mobile devices.
- Documentation is complete.
